## 一、代码（已入库，路径）
- `src/models/meal_macros_net.py` —— 五头模型（ResNet50, num_regression_targets=5, ImageNet 预训练骨干）
- `src/training/train_meal_macros.py` —— 训练/验证/测试脚本（带 mask 损失、验证归一化L1选模、507 测试）

## 二、运行（在 `yitu-zhika-code/` 下，用有 bf16 支持的 NVIDIA GPU）
```bash
# 正式训练（30 轮 / 批8 / 早停 patience=8 / 验证归一化L1选模 / 冻结后 507 测试）
# 注意：每个 seed 必须用独立 tag。脚本会拒绝写入非空输出目录（避免静默覆盖），
#       续跑必须显式加 --resume，且 manifest/协议变化时会被拒绝。
python src/training/train_meal_macros.py --tag v2_seed42 --seed 42

# 多种子（做统计）——独立 tag，不要复用同一个 tag
python src/training/train_meal_macros.py --tag v2_seed43 --seed 43
python src/training/train_meal_macros.py --tag v2_seed44 --seed 44

# 未完成的 tag 续跑（从 last.pt 恢复 model/optimizer/epoch/history/RNG）
python src/training/train_meal_macros.py --tag v2_seed43 --seed 43 --resume

# 断点恢复的验证方式：直接重复原命令不会自动续训，会以“拒绝覆盖”退出。
# （历史产物 v1 / v1_expanded 已存在，切勿再用同 tag 重跑覆盖。）

# （可选）从官方 2 目标权重迁移特征层、只新训 5 头：
python src/training/train_meal_macros.py --tag v2_from_rgb --seed 42 \
    --init-from checkpoints/meal_rgb_official_v1/best.pt

# 快速验证（1 轮冒烟）
python src/training/train_meal_macros.py --smoke --tag smoke --limit 2
```

### 产物与续跑语义（§6.2）
- `best.pt`：只含 `model/epoch/best/best_epoch/config`，可用 `torch.load(..., weights_only=True)` 加载（推理/评估侧只读它）。
- `last.pt`：续跑用，额外含 `optimizer/history/rng`（numpy 随机状态无法用 `weights_only=True` 反序列化，故 `--resume` 显式 `weights_only=False` 读取本地受信文件）。
- 中断安全：两个文件都先写 `.tmp` 再原子替换，强杀不会留下半写权重（已实测：中途强杀后目录内无 `.tmp`，`--resume` 从 `epoch+1` 继续）。


## 三、输出
- `checkpoints/meal_macros_v1/<tag>/{best,last}.pt`（best 按验证归一化 L1 选择）
- `results/meal_macros_train_v1/<tag>/{status.json,epochs.json,test_metrics.json,test_predictions.csv}`
  - `test_metrics.json`：逐目标（calories/mass/protein/carbohydrate/fat）MAE/RMSE/负预测数，及 `checkpoint_sha256`、`manifest_sha256`

## 五、验收口径（对齐方案 §十/§P1-B）
- 五个目标分别有来源（`nutrition5k_dishes_verified`）、单位（kcal/g）、独立验证指标。
- 训练中宏量缺失维度 mask=0 不参与损失，**不把未知补 0**；真实 0 保留且 mask=1。
- 分类同时给 CE（0.2 权重）；类别支持数/Macro-F1 在 `test_metrics.json` 之外需另跑分类统计（可 `eval_multitask_full.py`）。
- 物理非负输出的事后裁零**不做**（保留原值如实报告负预测数）；Huber 变体为可选改进。
