# 在线主模型切换核对表（label_schema v2 / 12 类）

日期：2026-09-10　用途：把在线 `/predict` 的主模型从当前 `v1_expanded`（11 类）切到
label_schema v2 的 12 类权重（或明确决定不切）时，逐项打勾；**不看评估结果不得切换**。

## 0. 现状（未切换）
- 在线主模型：`checkpoints/meal_macros_v1/v1_expanded/best.pt`（`meal_macros_v1`，`label_schema=v1_11class`），
  `/model-info` 与 `/predict` 的类别映射来自该权重自带的清单（`resolve_macros_manifest`）。
- 12 类修正权重：`checkpoints/meal_macros_v1/v3_corrected_seed42..44/best.pt`
  （`label_schema=v2_fruit_12class`，`num_classes=12`）。**评估完成前不切换。**

## 1. 切换前置条件（全部满足才可切）
- [ ] `v3_corrected_seed*` 三个种子都跑完，且**同一真值口径**下与 `v1_expanded` 对比完成
      （跨 schema 数字不可直接比，见 `docs/label_schema_v2_水果类_2026-09-10.md` §5）。
- [ ] 五目标（热量/重量/蛋白/碳水/脂肪）测试指标与运行间噪声（~1 kcal MAE）比较后**无实质退化**；
      若热量退化超过噪声量级，需在报告中写明权衡再决定。
- [ ] 逐类支持度审计（`scripts/audit_classification_support.py --manifest results/meal_macros_corrected_v2/manifest.json`）
      完成；`soup_stew/dessert/sauce_condiment` 不得宣称该类验收通过。
- [ ] 负预测数量与产品异常处理已确认（接口返回 `abnormal_fields`，小程序显示"待确认"，不裁零）。
- [ ] 回退方案明确：保留 `v1_expanded` 权重与其 11 类映射，不删除、不改名。

## 2. 切换步骤
1. **改权重指向**：`app/experiment_pipeline.py` 的 `MACROS_CKPT`（或引入 `ONLINE_MACROS_TAG` 配置项）
   指向新 tag 的 `best.pt`；`MACROS_MANIFEST` 不再被新路径使用（权重自带清单优先），
   但保留常量给旧权重与对照使用。
2. **小程序类别展示**（12 类必需）：
   - `miniprogram/pages/result/result.js`、`pages/nutritionist/nutritionist.js`：
     `CATEGORY_IDS` 增加 `'fruit'`，`CATEGORY_ZH` 增加 `fruit: '水果'`；
   - `miniprogram/pages/history/history.wxml` 的类别色点：为"水果"补一个颜色分支；
   - 否则 12 类模型返回"水果"时，标注/纠正下拉无法表示该类（`zhToId('水果')` 会返回 null）。
3. **后端类别校验（建议同时做）**：`app/collection.py` 目前对 `corrected_category` 不做白名单校验
   （`app/inference_service.py` 的 record 表默认示例值是 `vegetable`）。建议按**当前生效的
   label_schema** 校验并写入 `label_schema` 字段，避免旧 11 类与 12 类标注混入同一列而无法区分。
4. **重启并核对**：
   - `GET /model-info`：`primary_model_sha256` 为新权重、`label_schema=v2_fruit_12class`、
     `categories` 含 12 项（含 `fruit`）、`category_manifest` 指向修正清单；
   - `POST /predict`：`label_schema`、`category_manifest`、`category_name` 与之一致；
   - `python scripts/check_inference_consistency.py`：离线与 HTTP 逐字段一致（`all_pass: true`）。
5. **记录**：把切换时间、权重 SHA、`/model-info` 输出、一致性证据路径写入发布记录
   （`docs/release_checklist_2026-09-08.md` 追加一节）。

## 3. 回退步骤
1. `MACROS_CKPT` 改回 `v1_expanded/best.pt`；2. 重启服务；3. 复跑 `check_inference_consistency.py`；
4. 在发布记录中写明回退原因与时间。历史记录中的旧类别名与旧预测**不重写**。

## 4. 禁止事项
- 不得在未完成评估、或仅凭"权重文件存在"的情况下切换。
- 不得把 12 类 logits 用 11 类映射解释（反之亦然）——映射必须来自权重自带清单。
- 不得因为"水果类新增了"就宣称分类整体变准；跨 schema 的 Macro-F1 不可比。
- 不得删除旧权重或旧清单：它们是回退路径与对照基线。
