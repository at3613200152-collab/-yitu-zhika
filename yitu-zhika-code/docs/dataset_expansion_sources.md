# 食物训练数据扩充：来源核查与建议

核查日期：2026-09-04。本次只读调研并记录方案，没有下载数据包、注册、接受额外条款或启动训练。数量区分图像、视角和独立餐盘；增加图片不等于增加独立的热量监督样本。

## 决策摘要

建议先修复当前训练数值稳定性，再优先补充 Nutrition5k 中有真实营养标注但本机缺少图像的餐盘。Food-101 可单独做分类预训练；ECUSTFD 可做小规模重量/体积辅助验证；UECFOOD-256 待官方获取链路和去重规则核实后再考虑。这个排序是基于下述标注适配性的工程判断，不是已经证明的效果提升。

所有餐盘热量效果仍须在固定、隔离的 Nutrition5k 测试集上比较 RGB-only 与 RGB+预测NIR；不能把类别均值热量、推导标签或农场域 NIR 成绩写成餐盘真实热量提升。

## Food-101：分类预训练优先候选

- 101 个类别、101,000 张图像，每类 750 张训练图与 250 张人工复核测试图，即 75,750/25,250；训练标签有噪声，最长边 512 像素。官方主页标称下载包 5 GB，不是本机实测占用；解压与缓存还需预算空间。[ETH 官方主页](https://data.vision.ee.ethz.ch/cvl/datasets_extra/food-101/)
- 标注是图像类别，不提供逐餐盘实测重量、体积或热量。适合训练分类分支或共享视觉编码器，不能直接作为热量回归真值。[ETH 组织数据卡及字段](https://huggingface.co/datasets/ethz/food101)
- 主页可访问且提供下载入口，但本次没有下载验证完整性。许可说明称图片产权属于 Foodspotting 图片所有者，超出科学合理使用的用途需与相应所有者协商；数据卡许可证栏为 unknown。不能当成无条件商用授权；实际导入时保留原始许可文件与引用。[官方入口](https://data.vision.ee.ethz.ch/cvl/datasets_extra/food-101/)、[许可说明](https://huggingface.co/datasets/ethz/food101#licensing-information)
- 项目建议：独立分类任务预训练，保持官方测试隔离，再迁移到 Nutrition5k；不以类别平均热量补造每张图的热量标签。这是基于上述字段限制的方案建议。

## UECFOOD-256：分类/检测备选

- 官方说明确认 256 类，提供食物边界框、英文/日文类别表及多食物图片列表；主要涵盖日本及其他国家的常见食物。同一图片可能在不同类别目录重复出现，直接按文件随机划分可能泄漏。[作者项目页](https://foodcam.mobi/dataset256.html)
- 官方包说明未列重量、体积或每份热量标签；本题可用作分类/检测辅助，不应作为真实热量监督。[作者项目页](https://foodcam.mobi/dataset256.html)
- 精确独立图像总数、压缩包大小：本次未获可靠一手确认，保留未知；不采信二手资料间存在差异的精确计数。作者原论文是数据扩充方法，不能代替下载后对发布版逐文件去重审计。[作者论文](https://mm.cs.uec.ac.jp/e/pub/conf14/140912kawano_0.pdf)
- 官方明确仅限非商业研究，其他用途需联系作者。本次搜索可取得官方页面说明，但直接网页请求超时、本机 HTTPS 请求遇到证书验证失败；未绕过 TLS 校验，也未验证 ZIP 可下载。获取可靠性暂低于 Food-101。[官方用途限制与入口](https://foodcam.mobi/dataset256.html)
- 项目建议：暂列后备。未来若导入，按原始图片 ID/内容哈希合并重复文件，保留多标签和所有边界框，再按图片组划分；不要把多个目录里的同图当作独立样本。

## ECUSTFD：小规模重量/体积辅助，不是大规模餐盘基准

- 作者报告 19 类、2,978 张图；同一食物份量多次拍摄顶视和侧视，通常包含一元硬币标定物，单图不超过两类食物。图数不是独立食物份数，必须按物体/份量分组隔离。[作者仓库](https://github.com/Liang-yc/ECUSTFD-resized-)
- 缩小版提供边界框，重量用电子秤测得，体积用排水法测得；作者提醒体积可靠性不如重量。能提供真实重量/体积辅助监督。[原论文第 2 节](https://arxiv.org/html/1705.07632)
- 类别能量密度来自营养表，论文以体积、密度及能量密度计算热量；这不是独立测得的每份热量。若生成 kcal 标签，须明确标记为推导值、保存公式/单位/来源，不能混称 Nutrition5k 式营养监督。[原论文第 2、3 节](https://arxiv.org/html/1705.07632)
- GitHub 缩小版及标注入口可访问，原图与重量资料另有百度网盘入口；本次未核验网盘登录、文件可用性或压缩包大小，因此大小未知。作者称免费公开、请求论文引用，但所见根目录无独立标准 LICENSE；商用/再分发范围需额外核实，不能从公开仓库推定。[作者仓库及获取说明](https://github.com/Liang-yc/ECUSTFD-resized-)
- 作者指出 `mix002T(2)` 与 `mix005S(4)` 缺少标定物，不应用于份量估计验证。完整食物、标定硬币、顶侧双视角与当前单张混合餐盘场景存在差异，适合独立辅助实验而非替代主测试集。[作者勘误](https://github.com/Liang-yc/ECUSTFD-resized-#notice)、[采集协议](https://arxiv.org/html/1705.07632)

## 导入验收门槛

1. 保存作者来源、许可说明、版本、下载对象大小与哈希；来源不明/需要新授权的包先停。
2. 解码检查、图片内容去重、份量/餐盘分组；官方测试不用于训练或超参选择。
3. 每字段声明标签类型：实测、由原料表计算、类别标签或衍生标签；区分 g、kcal、cm³，不再根据列位置猜测语义。
4. 在相同测试集、训练预算和主干上比较扩充前后，以及 RGB-only/RGB+预测NIR；分类、NIR 生成和热量指标分开报告。

上述门槛是本项目建议，不表示三个外部数据集已经通过本机验收。
