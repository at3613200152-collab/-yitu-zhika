## 当前模型能力边界

- 分类为由配料归纳的 11 个粗类别，并非 11 道具体菜名，更不是全菜系识别；训练集实际覆盖其中 10 类。
- 当前模型输出一张餐盘图片的总热量和总重量，不提供每一道菜的分割及逐项重量。更细的菜名/逐项估计需要新增标签和相应模型工作。
- 预测 NIR 是相对强度预测，不是手机测得的真实近红外。
- RGB＋NIR 的单种子热量 MAE 较 RGB 仅改善 0.340 kcal，尚无稳定增益证据；不能把实验指标包装成单张用户照片的误差保证。
- CalorieCLIP 类基线只输出热量，不补造类别或重量。
- 原 Demo 的 TDEE/周食谱尚未核验，不作为已完成产品功能。2026-09-07 用户新增“下周饮食规划”要求，纳入后续交付范围。
