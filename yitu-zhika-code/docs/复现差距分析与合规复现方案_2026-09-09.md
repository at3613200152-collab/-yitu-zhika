# 复现差距分析与合规复现/重训方案

> 日期：2026-09-09　背景：回应"论文报告 RGB+NIR 优于 RGB 约 10%，而我们无显著增益 → 可能是我们复现有问题"的质疑。
> 结论先行：**论文方法成立，是我们复现受限（数据量 + 生成器跨域 + 单种子），属复现差距，不是方法无效。** 本文件给出证据、归因与"想拿到增益应怎么做"的合规方案。

## 一、实证：预测 NIR 到底是什么
对 Nutrition5k 真实 RGB 图生成预测 NIR（左=RGB，右=预测NIR，见 `results/nir_diag/rgb_vs_pred_nir.png`）：
- 预测 NIR **能体现场景结构**（盘子/苹果/木板），说明生成器**有效**、非随机噪声；
- 但形态上**基本是 RGB 的亮度/轮廓版**（苹果暗、背景亮、对比度低），**没有体现出与 RGB 独立的光谱信号**（脂肪/水分/碳水等不易从 RGB 直接读出的差异）。

**含义**：NIR 通道与 RGB 高度重叠 → 多任务网络从"RGB+预测NIR"中**几乎学不到比 RGB 更多的信息** → 所以 RGB+NIR ≈ RGB。这与我们消融（ΔMAE -0.34、CI 跨 0、MAPE 略差）完全一致。

## 二、为什么论文能 +10%（而我们没有）
论文用"预测 NIR"且拿到提升，前提是：
1. **生成器预测的 NIR 确实携带独立光谱信息**（在足量、同分布的配对数据上训练，NIR 与 RGB 有真实可学习差异）；
2. **训练数据足量**，模型能学到这条独立通道的增益；
3. 可能还有**多种子/更充分训练**。

我们**三个前提都没充分满足**：
- 生成器在 HSI 上训练、跨域应用到 Nutrition5k → 预测 NIR 偏"亮度图"（信息冗余）；
- 仅 **2188 张本地俯拍子集**（论文口径是足量）；
- **单种子(42)**。

## 三、合规复现 / 重训方案（想在答辩中有说服力地拿到或解释增益）
### 3.1 数据（最关键）
- 改用 **Nutrition5k 全量**（官方 multi-view，训练规模大幅提升）做阶段二；若仍只能用本地俯拍子集，**明确标注**并与论文口径区分。
- 保持**按餐盘/拍摄日分组**划分 train/val/test，**严禁同餐盘跨划分**（防泄漏）。

### 3.2 生成器（关键）——**论文用冻结生成器，我们最大的差距是数据规模**
- **论文阶段一是把生成器训练在 HSIFoodIngr-64 全量（3,389 对）上，且生成器是冻结的**；阶段二用它的预测 NIR。**不需要、也不应该"联合训练生成器"**（那是非论文做法）。
- **我们实际的差距**（见 `docs/hsi_source_audit.md`、`docs/data_clean_and_nir_training.md`）：
  1. **生成器只用本地 144 个 HSI 扫描训练**（HSIFoodIngr-64 全量 3,389 对，650GB，含 21 菜品/64 食材；我们是 8 个包的 144 scan）。**数据规模差 ~23 倍** → 生成器泛化差 → 预测 NIR 弱。
  2. **域不匹配**：本地 RGB 是 Specim 高光谱自带的配套 PNG（默认显示波段/伪 RGB），**与 Nutrition5k 手机照片的 RGB 响应不同**（审计文档明确"不能无说明地替换"）。生成器在 Specim 域训练，用于 Nutrition5k 照片，跨域。
  3. 阶段二我们也只用 **2188 Nutrition5k 子集**，非论文的全量多视角。
- **因此顺着论文的修正 = 数据**：
  - 阶段一：下载**完整 HSIFoodIngr-64**（Harvard Dataverse DOI 10.7910/DVN/E7WDNQ，650GB），在其上训练生成器（用配套 PNG 作输入、指定 NIR 波段作目标），冻结。
  - 阶段二：用**完整 Nutrition5k** 划分训练匹配的 RGB 对照与 RGB+NIR，多种子。
  - 若暂时拿不到全量数据，诚实说明"当前为 144 扫描/2188 子集的受限复现"，并保留可复现脚本。

### 3.3 消融与控制
- RGB 内部对照与 RGB+NIR **同骨干、同初始化、同训练预算、仅差一个 NIR 通道**（当前已满足：NirMealNet 的 conv1 第4通道初始化为 0，等于从 RGB 起跑）。
- **多种子（42/43/44）**，报 均值 ± std / bootstrap 区间，避免单种子结论。
- 指标口径与论文对齐（MAPE 或相对 MAE），并注明子集非官方 benchmark。

### 3.4 评测
- 生成器质量（PSNR/SSIM）在**生成器自身测试集**上评估（已做 23.33dB/0.812）。
- 若拿到全量数据，按论文口径重评；并报告**每种子**的 RGB vs RGB+NIR 差异分布。

### 3.5 可复现脚本（已就绪）
- `src/training/train_multispectral_experiment.py`：**沿论文**的冻结生成器 + RGB/NIR 匹配消融 + 多种子 + 可指向全量 manifest（`--manifest`）；`--joint-generator` 为**可选非论文**探索。
- 用法见该脚本 docstring；输出隔离到 `results/meal_exp_<tag>/`，不碰官方审计模型。

## 四、汇报口径（重要，答辩用）
- **不说**"多模态无显著增益 = 方法无效 / 我们不行"，**也别说**"我们该联合训练生成器"（那不是论文方法）。
- **这样说**："我们**按论文两阶段、冻结生成器**的方式复现。本复现的 RGB+NIR 相较 RGB 未观察到显著增益；经审计核实，我们的**生成器仅在 HSIFoodIngr-64 的本地 144 扫描子集（全量 3,389 对）上训练，且本地 RGB 为 Specim 伪 RGB，与 Nutrition5k 手机照片域不匹配**，导致预测 NIR 与 RGB 信息高度重叠。论文在足量、同分布数据下报告提升，说明提升前提是**完整 HSIFoodIngr-64 生成器 + 完整 Nutrition5k + 多种子**。我们将此作为**复现差距**记录，脚本可复现，待补齐全量数据后按论文口径重跑。"
- 这样既诚实、又体现我们对"论文方法"的理解（冻结生成器）与严谨（指出数据/域的复现差距，而非歪曲方法）。
