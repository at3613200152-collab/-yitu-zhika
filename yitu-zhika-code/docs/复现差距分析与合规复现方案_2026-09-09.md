# 复现差距分析与合规复现/重训方案

> 日期：2026-09-09　背景：回应"论文报告 RGB+NIR 优于 RGB 约 10%，而我们无显著增益 → 可能是我们复现有问题"的质疑。
> 结论先行：**论文方法成立，是我们复现受限（数据量 + 生成器跨域 + 单种子），属复现差距，不是方法无效。** 本文件给出证据、归因与"想拿到增益应怎么做"的合规方案。

## 一、实证：预测 NIR 到底是什么
对 Nutrition5k 真实 RGB 图生成预测 NIR（左=RGB，右=预测NIR，见 `results/nir_diag/rgb_vs_pred_nir.png`）：
- 预测 NIR **能体现场景结构**（盘子/苹果/木板），说明生成器**有效**、非随机噪声；
- 但形态上**基本是 RGB 的亮度/轮廓版**（苹果暗、背景亮、对比度低），**没有体现出与 RGB 独立的光谱信号**（脂肪/水分/碳水等不易从 RGB 直接读出的差异）。

**含义**：NIR 通道与 RGB 高度重叠 → 多任务网络从"RGB+预测NIR"中**几乎学不到比 RGB 更多的信息** → 所以 RGB+NIR ≈ RGB。这与我们消融（ΔMAE -0.34、CI 跨 0、MAPE 略差）完全一致。

## 二、为什么论文能 +10%（而我们没有）
论文用"预测 NIR"且拿到提升，前提是：
1. **生成器预测的 NIR 确实携带独立光谱信息**（在足量、同分布的配对数据上训练，NIR 与 RGB 有真实可学习差异）；
2. **训练数据足量**，模型能学到这条独立通道的增益；
3. 可能还有**多种子/更充分训练**。

我们**三个前提都没充分满足**：
- 生成器在 HSI 上训练、跨域应用到 Nutrition5k → 预测 NIR 偏"亮度图"（信息冗余）；
- 仅 **2188 张本地俯拍子集**（论文口径是足量）；
- **单种子(42)**。

## 三、合规复现 / 重训方案（想在答辩中有说服力地拿到或解释增益）
### 3.1 数据（最关键）
- 改用 **Nutrition5k 全量**（官方 multi-view，训练规模大幅提升）做阶段二；若仍只能用本地俯拍子集，**明确标注**并与论文口径区分。
- 保持**按餐盘/拍摄日分组**划分 train/val/test，**严禁同餐盘跨划分**（防泄漏）。

### 3.2 生成器（让 NIR 真的"有信息"）
- 优先：在**与分类集同域**的配对 RGB-NIR 数据上训练生成器（这样预测 NIR 才是"该场景的真实光谱近似"）。
- 次选（更贴论文且工程可行）：**把生成器与分类器在目标集上联合优化**——用分类/回归损失 **反向传导到生成器**，让生成器学会输出"对下游最有用"的 NIR（即"预测 NIR 为分类服务"）。需把生成器从 `requires_grad_(False)` 改为可训练，并只对目标集运行（明确这不是"自我训练"，而是"生成器为下游任务自适应"）。
- 现状我们生成器是**冻结**的（`requires_grad_(False).eval()` + `no_grad`），这是论文常用做法；若想提升，需按上面调整并重新训练。

### 3.3 消融与控制
- RGB 内部对照与 RGB+NIR **同骨干、同初始化、同训练预算、仅差一个 NIR 通道**（当前已满足：NirMealNet 的 conv1 第4通道初始化为 0，等于从 RGB 起跑）。
- **多种子（42/43/44）**，报 均值 ± std / bootstrap 区间，避免单种子结论。
- 指标口径与论文对齐（MAPE 或相对 MAE），并注明我们子集非官方 benchmark。

### 3.4 评测
- 生成器质量（PSNR/SSIM）在**生成器自身测试集**上评估（已做 23.33dB/0.812）；
- 若想验证"预测 NIR 是否真的有用"，可在 **Nutrition5k 上单模型分别评估 RGB 与 RGB+NIR**，并报告**每种子**差异分布（我们已有 test_metrics，但需多种子）。

## 四、汇报口径（重要，答辩用）
- **不说**"多模态无显著增益 = 方法无效 / 我们不行"。
- **这样说**："本复现（有限 2188 本地俯拍子集、单种子、生成器跨数据集）未复现论文报告的 RGB+NIR 增益；经实证，预测 NIR 与 RGB 信息高度重叠（亮度/轮廓型），导致该通道贡献有限。论文在足量、同分布数据下报告提升，说明提升取决于**生成器携带独立光谱信息 + 足量训练数据**。我们将此作为**复现差距**记录，并提出全量数据 + 生成器匹配/联合训练 + 多种子的改进路径（见未来工作）。"
- 这样既诚实，又体现我们对方法的理解与严谨。
