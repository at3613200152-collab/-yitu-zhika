# NIR 决定实验（RGB vs RGB+NIR × 3 seed）：结论与证据

日期：2026-09-10　对应方案：§7/§8「用实验决定 NIR 是否值得增加部署复杂度」
预注册判定规则（跑之前就定好）：**三种子 ΔCI 全跨 0，或跨种子符号不一致 → 判定"未观察到稳定增益"**。

## 1. 实验设置
| 项 | 值 |
|---|---|
| 脚本 | `src/training/train_multispectral_experiment.py`（本次修掉两处缺陷后重跑，tag `ms2_*`） |
| 数据 | 冻结 Nutrition5k 清单 2188/567/507；两臂同划分 |
| 对照 | 只差一个因素：`--mode rgb` 用 3 通道 ResNet50；`--mode rgbnir` 用 4 通道（RGB + 冻结生成器预测的 NIR） |
| 共同项 | 同骨干（ImageNet 预训练）、同优化器分组 lr、30 轮、batch 8、早停 8、验证归一化 L1 选模、静态冻结生成器（`checkpoints/hsi_unet_v2/best.pt`） |
| 种子 | 42 / 43 / 44（修好后采样种子真正随 `--seed` 变化） |
| 统计 | 同餐盘配对（按 dish_id 对齐两臂逐盘绝对误差）+ 10000 次重采样 bootstrap 95% CI |
| 证据 | `artifacts/paired-nir-ms2.json`；汇总 `scripts/summarize_ms2.py`、配对分析 `scripts/analyze_paired_nir.py` |

## 2. 结果（507 冻结测试集）
| seed | RGB 热量 MAE | NIR 热量 MAE | Δ(NIR−RGB) | 配对 95% CI | 跨 0 | RGB 重量 | NIR 重量 | Δ | 跨 0 |
|---|---|---|---|---|---|---|---|---|---|
| 42 | 58.55 | 60.87 | **+2.32** | [−0.47, +5.35] | 是 | 36.78 | 36.63 | −0.15 | 是 |
| 43 | 61.46 | 58.48 | **−2.98** | [−5.50, −0.52] | **否（NIR 更好）** | 39.09 | 36.22 | −2.87 | **否（NIR 更好）** |
| 44 | 57.63 | 60.81 | **+3.19** | [+0.68, +5.68] | **否（NIR 更差）** | 36.13 | 37.44 | +1.31 | 是 |
| 跨种子 | — | — | 均值 **+0.84**，范围 **[−2.98, +3.19]** | — | **符号翻转** | — | — | 均值 −0.57，范围 [−2.87, +1.31] | 符号翻转 |

另：MAPE 也随种子翻转（seed42 48.53%→59.41% 变差；seed43 54.99%→50.55% 变好；seed44 46.20%→48.56% 变差）。

## 3. 结论（按预注册规则）
1. **未观察到稳定增益。** 三种子的差值符号不一致（+2.32 / −2.98 / +3.19），跨种子均值 +0.84 kcal，
   而**跨种子极差 6.17 kcal** 远大于任何单次运行声称的效应。
2. **不为 NIR 增加部署复杂度**（不上线门控/多光谱分支）。生成器权重与代码保留，作为课程实验与后续研究方向。
3. **单次运行的"显著性"不可信**：只看 seed 43 会得到"−2.98 kcal，CI 不含 0，NIR 显著有效"的结论；
   只看 seed 44 会得到"显著更差"。这正是必须多种子的原因，也是本实验最有价值的方法论产物。

## 4. 一个必须同时披露的发现：种子波动比效应更大
- RGB 臂三个种子的热量 MAE：58.55 / 61.46 / 57.63 → **极差 3.84 kcal**；
- NIR 臂：60.87 / 58.48 / 60.81 → 极差 2.40 kcal；
- 而我们要检测的 NIR 效应跨种子均值只有 **0.84 kcal**。
→ 在本预算（30 轮、单卡、种子只影响初始化与采样顺序）下，**两目标协议的种子波动大于待测效应**，
  "NIR 有没有用"在这个精度水平上问不出答案；要回答必须显著降低波动（见 §5）。

## 5. 与历史结论的关系（口径说明）
| 来源 | 热量 MAE（RGB / RGB+NIR） | 说明 |
|---|---|---|
| 官方审计版 `meal_rgb/nir_official_v1` | 56.55 / 56.21（Δ −0.34，拍摄日分组 CI 跨 0） | 历史运行；其**选模指标**受累计计数缺陷影响（测试指标不受影响），且带 cudnn 确定性设置 |
| 缺陷版 `ms_rgb/rgbnir_seed42` | 60.60 / 56.42 | 采样种子硬编码 + 度量缺陷，**已作废** |
| 本次 `ms2_*` 三种子 | 58.55–61.46 / 58.48–60.87 | 修正协议；结论：无稳定增益 |

三者都指向同一结论：**NIR 在这套数据/生成器条件下没有可复现的收益**；差异的绝对值（0.34 / 2.32 / −2.98 …）
全部落在种子波动与配对噪声的量级内。

## 6. 想让 NIR 站得住需要什么（下一步）
1. **降低波动**：显式 `torch.use_deterministic_algorithms(True)` + `cudnn.deterministic=True`（官方脚本已用，多光谱/五头脚本未用）；
2. **提高生成器质量**：用全量 2772 训练样本重训（先修队友数据的 90° 朝向问题；见 `docs/全量生成器评估结论_2026-09-10.md`）；
3. **加大种子数**（≥5）并预注册判定规则，报告跨种子均值的置信区间而非单次 CI；
4. **换一个更能体现多光谱价值的对照**：直接喂两个视角/两个光照条件，而不是"RGB 派生的 NIR"——
   因为预测 NIR 与 RGB 信息高度重叠（可视化见 `results/nir_preview/`）。
