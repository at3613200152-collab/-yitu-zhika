# P1-C：扩展 128 餐盘 补数据对比结果

日期：2026-09-10　对比：旧(冻结 3262) vs 扩展(+128=3390)，同为 `train_meal_macros.py --tag v1 / v1_expanded`（五头、RGB、seed 42、批 8、早停 8、验证归一化L1选模、507 测试）。

## ⚠️ 2026-09-10 口径修正（必读）
同种子同配置重跑（`v1_expanded` vs `v2_seed42`，见 `docs/阶段四_扩展训练与可靠性核对_2026-09-10.md` §3）
显示 **GPU 存在运行间非确定性**：热量 MAE 波动 ~1.0 kcal（58.505 → 57.520）、粗分类准确率波动 ~1.2 个百分点，
且从第 1 轮验证损失就不同。因此：

- 表中"卡路里 ↓0.41、脂肪 ↓0.09、粗分类 ↑1%"**小于运行噪声**，**不能**作为"补数据收益"的证据；
- "重量 ↓2.26"大于噪声量级，方向上仍站得住，但**单种子**下仍需多种子配对复核；
- 本页第 17–18 行的"小幅正向收益"结论**降级为待验证**；在完成多种子配对比较前，
  对外只能表述为"单种子下重量指标改善、其余指标差异在噪声范围内"。

（原因：运行未启用 `torch.use_deterministic_algorithms(True)`；bf16 autocast 的归约/卷积算法选择等
会带来逐位不可复现的差异。）

## 结果（507 测试）
| 指标 | 旧 v1 (3262) | 扩展 v1_expanded (3390) | 变化 |
|---|---:|---:|---:|
| 卡路里 MAE (kcal) | 58.91 | **58.50** | ↓0.41 |
| 卡路里 RMSE | 88.40 | 88.20 | ↓0.20 |
| 重量 MAE (g) | 38.40 | **36.14** | ↓2.26 |
| 蛋白 MAE (g) | 5.71 | 5.71 | ≈ |
| 碳水 MAE (g) | 6.39 | **6.10** | ↓0.29 |
| 脂肪 MAE (g) | 4.41 | 4.32 | ↓0.09 |
| 粗分类准确率 | 0.7278 | **0.7377** | ↑~1% |

## 结论（诚实口径）
- **补 128 盘的方向性收益需多种子复核**：重量 MAE↓2.26 大于已测噪声量级（~1 kcal / ~1.2pt 的同类波动），
  但热量 ↓0.41 与粗分类 ↑1% 落在噪声范围内。**不是"带来显著提升"的强证据**；多种子配对比较完成前，
  不得宣称"数据扩容带来显著改进"（见上方口径修正）。
- 选模口径：v1_expanded 在**验证集与测试集均更优** → 在线宏量模型选用 **v1_expanded**（`checkpoints/meal_macros_v1/v1_expanded/best.pt`），`/predict` 已切换。官方两目标(RGB/NIR)仍保留对照可回退。
  （注：label_schema v2 的 12 类修正模型正在训练，是否替换在线模型待其评估结果。）
