## 二、运行（GPU，`yitu-zhika-code/` 下）
```bash
# 先小规模 smoke（每臂各 1 轮）确认不炸
python src/training/train_meal_ablation.py --arm nir_legacy  --seed 42 --smoke
python src/training/train_meal_ablation.py --arm factorized  --seed 42 --smoke
python src/training/train_meal_ablation.py --arm pair_control --seed 42 --smoke
python src/training/train_meal_ablation.py --arm consistency  --seed 42 --smoke
python src/training/train_meal_ablation.py --arm clip_aux     --seed 42 --smoke
python src/training/train_meal_ablation.py --arm combined     --seed 42 --smoke

# 正式：固定多种子（42/43），30 轮/批8/早停8/验证归一化L1选模，8h 预算
python src/training/train_meal_ablation.py --arm nir_legacy --seed 42 --epochs 30
python src/training/train_meal_ablation.py --arm nir_legacy --seed 43 --epochs 30
python src/training/train_meal_ablation.py --arm factorized --seed 42 --epochs 30
# ... 每个臂 × 每种子
```
输出：`results/meal_ablation_v2/<arm>_s<seed>/{status,epochs,test_metrics,completion_audit}.json`、
`checkpoints/meal_ablation_v2/<arm>_s<seed>/{best,last}.pt`。

## 三、对比口径（方案 §十）
- 每臂报 `test_metrics.json` 的五目标/两目标 MAE、RMSE、负预测数；分类报逐类支持数、Macro-F1、balanced accuracy、混淆矩阵（用 `scripts/audit_classification_support.py`）。
- 选模用**验证集**归一化 L1；**507 测试仅最终评估一次**，不反复挑。
- 组合/多因素不得把每一项都宣称有效（方案 §八.3）；CLIP 不能当油量/生熟/烹饪真值；NIR 门控值不是校准可靠性概率。
- 同盘多视图按聚类算区间，不当独立样本；MAPE/相对 MAE 分开，不删低热量样本。
