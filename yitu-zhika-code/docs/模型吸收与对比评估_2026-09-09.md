# 模型吸收与对比评估清单（branch2 / teammate 模型）

> 背景：branch2 可能是队友提交的新模型。目标：判断**可吸收的点 / 能否用它训练 / 能否直接套用**。
> 原则：新模型**先评估、再决定**，不静默替换已审计的官方 `meal_rgb_official_v1`/`meal_nir_official_v1`（对应课设§8.3：新模型通过质量/稳定性检查后再灰度替换，并保留回退）。

## 一、拿到模型后先做（一次性核验）
1. **文件性质**：是 `best.pt`（LFS 指针还是实体）？大小？`file` 类型；SHA256（记下）。
2. **能否用我们的加载接口加载**：
   - `MealNet`/`NirMealNet` 规格：`num_classes`（应为 11）、`input_channels`（3 或 4）、`num_regression_targets`（应为 2）、骨干 imageNet 预训练。
   - 用 `torch.load(..., weights_only=True)` 看键：`model`、`config`、`epoch`、`best_epoch`、`target_names`。
   - 与官方 `checkpoints/meal_rgb_official_v1/best.pt` 的 `config`/`protocol` 对比，确认是不是同 manifest/categories。
3. **溯源/审计**：是否有配套 `results/<run>/test_metrics.json`、`completion_audit.json`、`protocol.json`，manifest SHA 是否等于 `f1e293…`（与官方一致？）。
4. **类别数/类别顺序**：若 `num_classes`≠11 或类别映射与我们的 `CATEGORY_ZH`/`category_to_idx` 不同，**不能直接套用**（会错位），需要对齐或只吸收其训练方法。

## 二、决定"吸收 / 用它训练 / 直接套用"
| 情形 | 判断 | 动作 |
|---|---|---|
| 架构/类别/输入完全匹配，且**审计完整 & 在 507 测试集上 MAE < 56.55** | 可能是更好的模型 | **作为候选**：在固定 507 测试集上复评（`eval_multitask_full.py` 或 `experiment_pipeline`），与官方 56.55 对比；若确实更优且稳定 → 作为可选替换，评审后灰度 |
| 架构匹配但只是**中间权重/微调**（如更多 epoch、更大数据） | 有吸收价值 | 用它的**训练配置/数据划分/超参**作为改进参考，重跑我们的实验脚本 |
| 架构不同（类别数/输入/回归头不同） | 不可直接套用 | 只吸收其**思路/配置**（如新的 augmentation、NIR 使用方式），或单独作为另一基线 |
| 无法加载 / 无审计 / 缺 provenance | 不可靠 | 拒绝，仅作参考；不打乱官方模型 |

## 三、评估脚本（工具恢复后跑）
```bash
# 1) 加载并打印模型契约
python -c "import torch; c=torch.load('checkpoints/<teammate>/best.pt',map_location='cpu',weights_only=True); print(c.keys()); print(c.get('config'))"

# 2) 在固定 507 测试集复评 MAE/RMSE/R²（与官方 56.55/85.13/0.839 对比）
python src/evaluation/eval_multitask_full.py --checkpoint checkpoints/<teammate>/best.pt

```

## 四、对接我们现有系统的方式
- **作为"候选上线模型"**：满足 审计+provenance+更优 才放入 `model_card` 与 `ONLINE_MODEL_*`（`inference_service.py`），并保留官方版本可回退。
- **作为"对比基线"**：在课设 P12/P17 的三模型对比里，若它显著优于官方，可作为"更强的复现结果"补充说明（但需与作者论文口径区分，注明非官方 benchmark）。
- **只吸收训练配置**：比如它用了更多数据/新增强，则把这些写进 `train_multispectral_experiment.py` / config，用我们的数据重跑。

## 五、注意
- **别静默替换**官方模型（我们所有数字/报告/上线都锚定 `meal_rgb_official_v1`/`meal_nir_official_v1` 的 audit）。
- 若 branch2 模型类别数与类别顺序与官方不一致，**绝不直接套用**（分类标签会错位），需先对齐映射。
- 判断"谁更好"必须在**同一冻结 507 测试集**上比较，且多种子/多次采样别只看单次 MAE。
