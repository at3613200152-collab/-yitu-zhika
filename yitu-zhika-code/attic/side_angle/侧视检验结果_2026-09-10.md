# 侧视检验结果（2026-09-10）

> 目标：回答"能否用 Nutrition5k 侧视图检验我们的模型"。
> 数据位置见 `docs/侧视图位置与检验说明_2026-09-10.md`；本文件只记结果与解读。
> 证据：`scripts/eval_side_views.py` → `artifacts/side-view-eval-20260910-140710.json`；
> `scripts/check_side_frame_duplication.py` → `artifacts/side-frame-duplication.json`。

## 1. 结论速览
1. **侧视三帧不是三个独立样本**：`frame_0030` 与训练帧 `frame_0000` 的平均像素绝对差仅 **0.0107**（≈1 秒后的视频帧），
   `frame_0060` 为 **0.0612**；而"两张完全不同的图"通常在 0.15 以上 →
   用 0030/0060 做"泛化/鲁棒性"检验**不成立**，它测的是**近重复帧上的记忆效果**。
2. **视角是真实且巨大的域偏移**：只用俯拍数据训练的权重（`v1`，3262）在侧视帧上
   热量 MAE **124.5 kcal（相对误差 ≈94%）**、重量 MAE **117.2 g（≈113%）**、类别 acc **0.596**；
   而它在俯拍 507 测试集上是 58.91 kcal / 38.40 g / 0.728。
3. 因此我们对外报告的主指标（**俯拍** 507 测试：热量 MAE 58.50、相对 ≈23%）**不能外推到用户随手斜拍/侧拍的场景**；
   产品侧必须**引导俯拍**并披露角度敏感性（当前小程序**没有任何俯拍提示**）。

## 4. 必须一起看的混淆项：这 128 道菜本身就是小份餐
| 集合 | n | 热量均值/中位 | 重量均值/中位 |
|---|---|---|---|
| 侧视 128 道（全部在 train） | 128 | **133.2 / 91.8 kcal** | **103.6 / 79.0 g** |
| 冻结 507 测试 | 507 | 255.5 / 226.0 kcal | 198.5 / 161.0 g |
| 冻结 3262 训练 | 2188 | 253.0 / 209.6 kcal | 218.4 / 185.0 g |

所以**只能比较相对误差**：
| 模型 / 场景 | 热量相对误差（MAE/均值） | 重量相对误差 |
|---|---|---|
| `v1_expanded` 侧视 0030+0060 | 27.31 / 133.2 ≈ **20.5%** | 16.40 / 103.6 ≈ **15.8%** |
| `v1_expanded` 俯拍 507 测试 | 58.50 / 255.5 ≈ **22.9%** | 36.14 / 198.5 ≈ **18.2%** |
| `v1` 侧视 0030+0060 | 124.54 / 133.2 ≈ **93.5%** | 117.20 / 103.6 ≈ **113%** |
| `v1` 俯拍 507 测试 | 58.91 / 255.5 ≈ 23.1% | 38.40 / 198.5 ≈ 19.3% |

→ `v1_expanded` 在侧视上的相对误差**看起来与俯拍相当**（20.5% vs 22.9%），
但这批菜在它训练集里、评测帧又近乎重复（§2）→ **属于记忆，不是视角泛化**。
→ `v1` 的对比才是有意义的信号：**只用俯拍训练 → 侧拍场景相对误差从 ~23% 恶化到 ~94%/113%**。

## 5. 能说 / 不能说
**能说**：
- 侧视图位置、数量、与训练集的关系（128 道全在 train，训练帧固定为 `frame_0000`）；
- 三帧近乎重复这一事实，以及由此**否掉**"用 0030/0060 当未见样本"的做法；
- 俯拍训练模型在侧视场景上**严重失效**（相对误差 ~94%/113%）——这是产品相关的真实风险信号；
- 加入 128 道侧视训练后，**同一批菜/同一视频的侧视帧**误差降到 ~20%（但不可外推）。

**不能说**：
- 不能说"模型已具备侧视拍照能力"（无任何未见菜的侧视图可测）；
- 不能说"侧视评测证明我们的 58.5 kcal 有泛化性"（口径是俯拍 507）；
- 不能拿侧视 27 kcal 与俯拍 58 kcal 直接比较（菜品的份量分布差一半，见 §4）。

## 6. 对产品的影响（建议）
1. **小程序补"请俯拍"引导**：现在 `result.wxml`/拍照页没有任何角度提示，用户斜拍或侧拍时误差可能数倍放大；
   建议在拍照页与结果页提示"请从正上方俯拍整盘食物"。
2. **披露角度敏感性**：结果页可加一行说明"本模型基于俯拍训练，斜拍/侧拍误差会明显变大"。
3. **不要把"另一角度照片"混入精度统计**：标注入口（"补充另一角度照片"）可用于收集数据，
   但侧角度样本只能单独统计，不得并入俯拍精度口径。
